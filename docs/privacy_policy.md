# USF SmartStudy Spaces - Privacy Policy

## Data Collection
1. **Personal Data:**
   - USF NetID (for authentication)
   - Email address (for notifications)
   - Calendar data (only with explicit consent)

2. **Usage Data:**
   - Study space booking history
   - System interaction logs
   - Device information (for mobile app)

## Data Usage
- Provide and maintain service functionality
- Improve user experience
- Generate anonymized utilization reports
- Ensure system security and prevent abuse

## Data Protection
- All data encrypted in transit (TLS 1.2+)
- Personal data encrypted at rest (AES-256)
- Regular security audits and penetration testing
- Access restricted to authorized personnel only

## User Rights
1. **Access:** Users may request copies of their personal data
2. **Correction:** Users may update inaccurate information
3. **Deletion:** Users may request data deletion (excluding legally required records)
4. **Opt-Out:** Users may disable non-essential data collection

## Compliance
- Family Educational Rights and Privacy Act (FERPA)
- General Data Protection Regulation (GDPR)
- USF Institutional Data Policy
