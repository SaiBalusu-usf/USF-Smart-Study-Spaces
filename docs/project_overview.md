# USF SmartStudy Spaces - Project Overview

## Project Goals
- Provide real-time visibility into study space availability across USF campuses
- Enable students to book study spaces seamlessly
- Integrate with student calendars to suggest optimal study times
- Reduce overcrowding in popular study areas

## Technical Stack
- **Backend:** Azure Functions (Node.js), Azure Cosmos DB
- **Frontend:** 
  - Web: React + Tailwind CSS
  - Mobile: React Native
- **APIs:** Microsoft Graph API (Calendar), USF Booking System API
- **Maps:** Azure Maps for space visualization

## Key Features
1. Real-time occupancy tracking using IoT sensors
2. Interactive campus maps showing space availability
3. Calendar integration for smart scheduling
4. Cross-platform accessibility (web + mobile)
5. Privacy-focused data handling

## Project Timeline
- Phase 1: Core infrastructure (4 weeks)
- Phase 2: Web interface (3 weeks)
- Phase 3: Mobile app (3 weeks)
- Phase 4: Testing & deployment (2 weeks)
